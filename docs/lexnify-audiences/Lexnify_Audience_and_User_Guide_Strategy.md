# Lexnify -- Audience & User Guide Strategy Blueprint

Version: 1.0\
Purpose: Define who our users are and how to design a simple, visual,
non-technical user guide.

------------------------------------------------------------------------

## 1. Who Are Our Users?

### Primary Audience

Small and mid-level event organizers such as:

-   College fest coordinators
-   NGO organizers
-   Religious/community event managers
-   Coaching center owners
-   Society event planners
-   Local workshop hosts

They are not technical users. They use apps for outcomes, not systems.

------------------------------------------------------------------------

## 2. User Psychology

Our users:

-   Are action-focused, not system-focused
-   Prefer mobile-style simplicity
-   Get confused by too many options
-   Avoid reading long text
-   Fear breaking something
-   Want reassurance and clarity

They need: - Step-by-step guidance - Clear buttons - Visual examples -
Emotional reassurance

------------------------------------------------------------------------

## 3. Why They Get Confused

Common confusion areas:

-   Too many options during event creation
-   Words like "slug", "toggle", "template"
-   Date and time window logic
-   Multiple check-in modes
-   Fear of QR code failure
-   Fear of losing data

------------------------------------------------------------------------

## 4. User Guide Creation Principles

The guide must NOT:

-   Be technical
-   Be paragraph heavy
-   Sound like documentation
-   Assume system knowledge

The guide MUST:

-   Use screenshots for every major action
-   Use arrows and highlights
-   Show one action per page
-   Use short sentences
-   Include reassurance messages

Example reassurance tone:

-   "Don't worry, you can edit this later."
-   "Nothing will be deleted."
-   "Just click this button."

------------------------------------------------------------------------

## 5. Guide Structure (Tab-Based)

The final user guide should have these sections:

1.  Getting Started
2.  Creating Your First Event
3.  Adding Contacts
4.  Sending WhatsApp Messages
5.  Public Registration Page
6.  Check-In (Very Important)
7.  Viewing Reports
8.  Subscription & Billing
9.  Safety & Data

Each section should include:

-   Short introduction
-   Screenshot
-   3--5 simple steps
-   Common mistake warning
-   "Don't worry" reassurance box

------------------------------------------------------------------------

## 6. Visual & Design Alignment

The guide must:

-   Match Lexnify colors
-   Use same font style
-   Use rounded UI elements
-   Highlight important buttons visually
-   Avoid clutter

The guide should feel friendly, not instructional or strict.

------------------------------------------------------------------------

## 7. Core Philosophy

The guide is not documentation.

It is emotional support + clarity for simple organizers.

If they feel safe, they will continue using Lexnify.
