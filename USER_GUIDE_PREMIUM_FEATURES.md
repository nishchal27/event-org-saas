## 📊 Analytics Dashboard

### Overview

The Analytics Dashboard provides real-time insights into your event performance, attendance trends, and engagement metrics.

### Key Metrics

**Events This Month**
- Current month's event count
- Trend indicator (↑↓) showing change from last month
- Comparison with previous month

**Confirmed Attendees**
- Total confirmed attendees this month
- Trend indicator showing growth/decline
- Helps track engagement over time

**Response Rate**
- Percentage of invited attendees who responded
- Visual progress bar
- Key metric for measuring engagement

**Upcoming Events**
- Count of scheduled future events
- Quick view of what's coming

### Charts & Trends

**Events Created (6 Months)**
- Bar chart showing event creation trends
- Identify busy months
- Plan for future capacity

**Attendance Trends (6 Months)**
- Area chart showing confirmed attendees over time
- Track growth patterns
- Identify successful event types

### How to Use

1. Navigate to Dashboard
2. View key metrics at the top
3. Scroll down to see charts
4. Use insights to:
   - Plan future events
   - Identify best-performing event types
   - Track engagement improvements

## 📋 Event Templates

### What Are Templates?

Templates are saved event configurations that you can reuse to quickly create similar events. Perfect for recurring events like weekly classes, monthly meetups, or regular workshops.

### Creating a Template

**From Event Form:**
1. Create an event with all desired settings
2. Fill in title, description, location, times, etc.
3. (Future: "Save as Template" button will be available)

**From Templates Page:**
1. Go to Templates (coming soon)
2. Click "Create Template"
3. Fill in template details
4. Save

### Using Templates

1. Go to "Create New Event"
2. Select a template from the dropdown at the top
3. Form automatically pre-fills with template data
4. Update dates, times, and any other details
5. Create event

### Managing Templates

- View all templates
- Edit template details
- Delete unused templates
- Templates are organization-specific

**Best Practices:**
- Create templates for common event types
- Update templates as your needs change
- Name templates clearly (e.g., "Weekly Yoga Class")

## 📥 CSV Export

### Exporting Events

1. Go to Events page
2. Click "Export" button (coming soon to list page)
3. CSV file downloads automatically
4. Open in Excel, Google Sheets, or any spreadsheet app

**Exported Data:**
- Title, Date, Start/End Time
- Location, Location Type
- Attendee count
- Max Capacity
- Status (Open/Closed)
- Created date

### Exporting Contacts

1. Go to Contacts page
2. Click "Export" button
3. CSV file downloads automatically

**Exported Data:**
- Name, Phone, Email
- Location
- Tags
- Events attended count
- Created date

### Exporting Attendance Reports

1. Go to Event Detail page
2. Click "Export" button in header
3. CSV file downloads with event name in filename

**Exported Data:**
- Attendee name, phone, email
- RSVP status (confirmed/declined/maybe)
- Waitlist status
- Check-in status
- WhatsApp sent status
- Registration date

**Use Cases:**
- Backup your data
- Generate reports for stakeholders
- Import into other tools
- Share with team members
- Analyze in spreadsheet software

## 📱 QR Code Check-in

### How It Works

Each event automatically gets a unique QR code when created. This QR code can be used for on-site check-in.

### For Event Organizers

**View QR Code:**
1. Go to Event Detail page
2. Click "Check-in" button
3. QR code is displayed
4. Download or print for on-site use

**Manual Check-in:**
1. Go to Event Detail → Attendees tab
2. Find attendee in list
3. Click "Check In" button (coming soon)
4. Attendee status updates to "Checked In"

**Check-in Status:**
- Green "✓ Checked In" badge on attendee list
- Check-in timestamp recorded
- Count shown in Quick Stats sidebar

### For Attendees

**Using QR Code:**
1. Event organizer displays QR code at venue
2. Attendee scans QR code with phone
3. Enters phone number
4. Automatically checked in

**Benefits:**
- Fast, contactless check-in
- Accurate attendance tracking
- Real-time updates
- Professional experience

## 👥 Contact Groups

### What Are Groups?

Contact groups help you organize contacts into categories for better management and targeted messaging.

### Creating Groups

1. Go to Contacts page
2. Click "Create Group" (coming soon)
3. Enter group name and description
4. Select contacts to add
5. Save

**Example Groups:**
- "VIP Members"
- "Regular Attendees"
- "New Members"
- "Workshop Participants"
- "Community Leaders"

### Using Groups

**In Event Creation:**
1. When creating event
2. Select "Selected Contacts" audience
3. Choose contact group
4. All group members automatically selected

**Benefits:**
- Faster event creation
- Targeted invitations
- Better organization
- Bulk operations

### Managing Groups

- View all groups
- Edit group members
- Delete groups
- Groups don't delete contacts

## 🎫 Capacity Limits & Waitlist

### Setting Capacity

1. When creating/editing event
2. Find "Maximum Capacity" field
3. Enter number (e.g., 20, 50, 100)
4. Save event

### How Waitlist Works

**Automatic:**
- When event reaches capacity
- New registrations automatically go to waitlist
- Waitlist badge shown on attendee

**When Spots Open:**
- If someone declines
- Waitlist attendees can be promoted
- Manual promotion available (coming soon)

### Viewing Capacity

**Event Detail Page:**
- Capacity card shows "X / Y spots filled"
- Waitlist count displayed
- Visual indicators

**Attendee List:**
- Waitlist badge on waitlisted attendees
- Confirmed vs waitlist clearly marked

**Best Practices:**
- Set realistic capacity limits
- Monitor waitlist for popular events
- Consider creating additional sessions

## 🔄 Recurring Events

### Duplicating Events

**Simple Duplicate:**
1. Go to Events list
2. Click menu (⋮) on event
3. Select "Duplicate"
4. New event created with same details

**Duplicate with Date Shift:**
1. Click menu (⋮) on event
2. Select "Duplicate (Next Week)"
3. Dialog opens
4. Enter days to shift (e.g., 7 for next week)
5. Click "Duplicate Event"
6. New event created with shifted date

**Use Cases:**
- Weekly classes (shift by 7 days)
- Monthly meetups (shift by 30 days)
- Recurring workshops
- Regular training sessions

**Auto-Features:**
- Title updated with "Next Session"
- All other details copied
- New QR code generated
- Fresh attendee list

## 🆘 Troubleshooting

### Analytics Not Showing
- Ensure you have events created
- Check date ranges
- Refresh dashboard

### Template Not Loading
- Verify template exists
- Check template permissions
- Try refreshing page

### Export Not Working
- Check browser download settings
- Ensure pop-ups allowed
- Try different browser

### QR Code Not Displaying
- Verify event has QR code
- Check event permissions
- Contact support if issue persists
