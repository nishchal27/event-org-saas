## Getting Started

### Quick Start (10 Minutes)

1. **Sign Up / Sign In**
   - Create your account
   - Create your organization
   - Set organization name

2. **Add Contacts**
   - Go to Contacts
   - Add your first contact
   - Or import via CSV

3. **Create Your First Event**
   - Go to Events → New Event
   - Fill in event details
   - (Optional) Select a template
   - Create event

4. **Send Invitations**
   - Go to Event Detail
   - Click "Invite" tab
   - Select contacts
   - Send WhatsApp invitations

5. **View Analytics**
   - Go to Dashboard
   - See your metrics
   - View charts and trends

## Core Features

### Event Management

#### Creating Events
1. Navigate to **Events** → **New Event**
2. Fill in required fields:
   - Event title
   - Date and time
   - Location (physical or online)
   - Description
3. (Optional) Add custom fields
4. (Optional) Upload event image
5. Select audience type
6. Click **Create Event**

#### Managing Events
- **Edit:** Click edit button on event card
- **Duplicate:** Use duplicate option for recurring events
- **Delete:** Soft delete (can be recovered)
- **Preview:** View public event page
- **Copy Link:** Share event link

#### Public Event Pages
- Each event has a unique public URL
- No login required for attendees
- Mobile-optimized design
- RSVP directly from page

---

### Contact Management

#### Adding Contacts
1. Go to **Contacts**
2. Click **Add Contact**
3. Fill in:
   - Name (required)
   - Phone (required)
   - Email (optional)
   - Location (optional)
   - Tags (optional)
   - Notes (optional)
4. Click **Save**

#### Managing Contacts
- **Search:** Use search bar to find contacts
- **Edit:** Click on contact card to edit
- **Delete:** Remove contact (attendance history preserved)
- **Export:** Download contacts as CSV

#### Contact Tags
- Add tags to categorize contacts
- Filter by tags
- Use for targeted invitations

---

### WhatsApp Invitations

#### Sending Invitations
1. Go to event detail page
2. Click **Invite** tab
3. Select contacts (or use groups)
4. (Optional) Generate AI message
5. Click **Send Invitations**

#### AI Message Generation
- Click **Generate Message** button
- Select tone: Friendly, Formal, or Casual
- AI creates personalized message
- Edit if needed before sending

#### Message Tracking
- See sent count
- Track delivery status
- View who received invitations

## Premium Features

### Analytics Dashboard

#### Overview Metrics
- **Events This Month:** Current month's event count with trend
- **Confirmed Attendees:** Total confirmed with trend
- **Response Rate:** Percentage of invited who responded
- **Upcoming Events:** Count of future events

#### Charts & Trends
- **Events Created (6 Months):** Bar chart showing creation trends
- **Attendance Trends (6 Months):** Area chart showing attendance over time

#### How to Use
1. Navigate to **Dashboard**
2. View key metrics at the top
3. Scroll down to see charts
4. Use insights to:
   - Plan future events
   - Identify best-performing event types
   - Track engagement improvements

### Event Templates

#### Creating Templates

**From Event Form:**
1. Create an event with all desired settings
2. Fill in title, description, location, times, etc.
3. Click **Save as Template**
4. Enter template name
5. Save

**From Templates Page:**
1. Go to **Events** → **Templates**
2. Click **Create Template**
3. Fill in template details
4. Save

#### Using Templates
1. Go to **Create New Event**
2. Select a template from the dropdown at the top
3. Form automatically pre-fills with template data
4. Update dates, times, and any other details
5. Create event

#### Managing Templates
- View all templates
- Edit template details
- Delete unused templates
- Templates are organization-specific

**Best Practices:**
- Create templates for common event types
- Update templates as your needs change
- Name templates clearly (e.g., "Weekly Yoga Class")

### CSV Export

#### Exporting Events
1. Go to **Events**
2. Click **Export** button
3. CSV file downloads automatically
4. Open in spreadsheet app

#### Exporting Contacts
1. Go to **Contacts**
2. Click **Export** button
3. CSV file downloads automatically
4. Open in spreadsheet app

#### Exporting Attendance
1. Go to event detail page
2. Click **Attendees** tab
3. Click **Export Attendance** button
4. CSV file downloads with all attendee data

**Note:** Export is available on Monthly+ plans.

### QR Code Check-in

#### For Attendees

**Getting Your QR Code:**
1. Register for event (via public page or invitation)
2. QR code appears immediately after registration
3. Download QR code as PNG
4. Save to phone gallery
5. Or share via native share API

**At the Event:**
1. Show your QR code to organizer
2. Organizer scans your QR code
3. You're checked in instantly!

**Fallback Options:**
- If you forgot your QR, scan the event QR code
- Or organizer can check you in manually

#### For Organizers

**Setting Up Check-in:**
1. Go to event detail page
2. Click **Scan QR** button
3. Grant camera permission
4. Start scanning attendee QR codes

**Scanner Features:**
- Real-time camera scanning
- Instant check-in on scan
- Visual feedback (success/error)
- Recent scan history
- Real-time stats

**Manual Check-in:**
1. Go to event detail page
2. Click **Check-in** button
3. Search for attendee
4. Click **Check In** button

**Check-in Analytics:**
- See check-in method breakdown
- View percentages
- Track efficiency

### Contact Groups

#### Creating Groups
1. Go to **Contacts** → **Groups**
2. Click **Create Group**
3. Enter group name and description
4. Select contacts to add
5. Save

#### Managing Groups
- **Edit:** Update group name, description, or contacts
- **Delete:** Remove group (contacts remain)
- **View:** See all contacts in group

#### Using Groups
- Select groups when sending invitations
- Filter contacts by group
- Organize contacts for better management

**Best Practices:**
- Create groups for different categories (e.g., "VIP Members", "Regular Attendees")
- Update groups regularly
- Use groups for targeted messaging

### Capacity Limits & Waitlist

#### Setting Capacity
1. When creating/editing event
2. Set **Maximum Capacity** field
3. Save event

#### How It Works
- When event reaches capacity, new registrations go to waitlist
- Waitlist attendees are automatically promoted when spots open
- Capacity is tracked in real-time

#### Managing Waitlist
- View waitlist in event detail page
- See waitlist count
- Promote waitlist attendees manually if needed
